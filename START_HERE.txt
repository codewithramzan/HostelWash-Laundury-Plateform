HOSTELWASH — LOCAL SETUP

1. Extract the hostelwash folder to C:\laragon\www\hostelwash.
2. Start Apache and MySQL in Laragon.
3. Import database/hostelwash.sql in phpMyAdmin.
4. Copy .env.example to .env and enter your database credentials.
5. Point hostelwash.test to C:/laragon/www/hostelwash/public.
   README.md contains the exact Apache virtual-host example.
6. In Laragon Terminal, inside the project folder:

   php bin/doctor.php
   php bin/create-admin.php

7. Open http://hostelwash.test/login and sign in using the admin you created.
8. Add Hostels and Rooms. Create a representative user, then assign that
   user to a hostel using the Representatives page.
9. Register a student account and schedule a pickup.

NO NODE.JS OR COMPOSER INSTALL IS NEEDED.
NO DEFAULT ADMIN PASSWORD IS INCLUDED.

Alternative local server:
   Set APP_URL=http://127.0.0.1:8000 in .env
   php -S 127.0.0.1:8000 -t public public/router.php

Optional demo hostels and rooms:
   php bin/demo-data.php --confirm

Local reset emails:
   php bin/read-mail.php

Payments: cash receipts are implemented. No online gateway is connected.
Code: application source is readable; only third-party vendor distributions
retain their original minified format.

See README.md for full setup, email, deployment and troubleshooting.
See TEST_REPORT.md for validation results.
